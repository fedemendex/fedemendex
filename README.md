# Hi, I'm Federico

I'm a backend engineer based in Berlin. I've been writing software professionally for more than ten years, mostly working on distributed services and cloud platforms.

These days I work mainly in **Go**. I enjoy the parts of backend development that involve system design, API design, observability, and finding straightforward ways to make complicated systems easier to operate.

## What I work with

- **Languages:** Go, Python, Java, Kotlin, TypeScript
- **Backend:** Distributed systems, microservices, REST APIs, identity and authorization
- **Data:** PostgreSQL, MySQL, Redis
- **Cloud and infrastructure:** Kubernetes, Docker, Azure, AWS, GCP
- **Observability:** OpenTelemetry, New Relic, Elasticsearch

## Outside backend engineering

I'm studying **theoretical and mathematical physics** part-time at The Open University. I'm interested in physical modelling and in using code to explore systems that can be difficult to build an intuition for on paper.

Electronic music and modular synthesis have also been long-running interests of mine. I'm currently building [**PatchAtlas**](https://patchatlas.cv), a site for discovering, creating, and sharing modular synthesizer patches. It's where a lot of my software background meets an increasingly serious music hobby.
