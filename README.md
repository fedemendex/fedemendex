# Hi, I'm Federico

I'm a backend engineer based in Berlin. I've been writing software professionally for more than ten years, mostly working on distributed services and cloud platforms.

These days I work mainly in **Go**. I enjoy the parts of backend development that involve system design, API design, observability, and finding straightforward ways to make complicated systems easier to operate.

More recently, I've been exploring **applied AI engineering**, particularly integrating LLMs into backend systems, local inference, and building reliable applications around probabilistic model outputs.

- **Data:** PostgreSQL, MySQL, Redis, SQLite

## Projects

### [PatchAtlas](https://patchatlas.cv)

A web application for discovering, creating, and sharing modular synthesizer patches. Built with Go, React/TypeScript, PostgreSQL, and Google Cloud.

It's where a lot of my software background meets an increasingly serious electronic music hobby.

### JobHunter

An AI-powered job discovery and matching application built with Go, React/TypeScript, and SQLite.

It collects job postings, extracts requirements using a locally hosted Qwen model through Ollama, and evaluates their suitability against a configurable professional profile.

The project explores some of the engineering challenges of working with LLMs: structured outputs, evidence verification, deterministic scoring, fault-tolerant background processing, and evaluation using human-reviewed results.
